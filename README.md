## 바로 쓰게 만들기
### 방법 A (추천) - 키 숨기기
1. https://aistudio.google.com/apikey 에서 Gemini 키 발급
2. worker.js 맨 위 설명대로 Cloudflare Worker 만들고 GEMINI_KEY 비밀값 등록
3. Worker 주소를 config.js 의 PROXY_URL 에 넣기
### 방법 B (간단) - 키 직접 넣기
1. config.js 의 GEMINI_KEY 에 키 넣기
2. Google Cloud 콘솔 → API 및 서비스 → 사용자 인증 정보 → 그 키 → 웹사이트 제한: luminahae.github.io/*
   (GitHub에 공개되면 Google이 유출된 키로 판단해 막을 수 있음)
